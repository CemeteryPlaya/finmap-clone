## Что уже совпадает

Это менять не нужно:
- **Шапка:** тёмная, с белой карточкой контента со скруглением. Кнопки Доход, Расход и Перевод стоят по центру в том же порядке.
- **Левая панель:** «Всего на счетах» и список счетов с балансами; панель сворачивается.
- **Колонки журнала:** тот же порядок — чекбокс, Дата, Сумма, Счёт, Контрагент, Категория/Статья, Проект, Комментарий.
- **Сортировка:** по умолчанию по дате, новые сверху. Клик по строке открывает операцию.
- **Наведение на строку:** вся строка подсвечивается светло-серым, кнопок действий на строке нет ни у них, ни у нас (`v2/02-row-hover.png` и `v2/c02-row-hover.png`). **Расхождения нет.**
- **Окно «Фильтр»:** есть «Готово» и «Сохранить фильтр».
- **Загрузка списка:** бесконечная прокрутка.
