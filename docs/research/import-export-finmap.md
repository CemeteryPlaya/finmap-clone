# Импорт и экспорт в Finmap: что увидели (2026-10-12, только чтение)

Скриншоты: `docs/research/screens/v2/40-export-click.png`, `41-import-panel.png`, `42-import-excel.png`, `43-export-custom.png`. Ничего в Finmap не сохраняли и не загружали; выгрузку журнала и шаблон скачали, их содержимое в репозиторий не кладём.

## Экспорт («Экспортировать в», значок ⤓ в тулбаре журнала)
- Меню из двух пунктов: **«Excel»** и **«Собрать Excel»**.
- **«Excel»** — файл `«<Компания> - Журнал - ДД-ММ-ГГГГ ЧЧ-ММ.xlsx»`, один лист `ExportRU`, без строки итогов, 16 колонок в формате шаблона импорта (ниже). Тип операции отдельной колонкой не пишется — он следует из «Со счета» / «На счет».
- **«Собрать Excel»** (окно, `43-export-custom.png`):
  - вверху превью — таблица с примером данных и строкой «Итого»; колонки переставляются перетаскиванием заголовка, у заголовка «×» убирает колонку;
  - «Что выгрузить» — чипы-переключатели по группам:
    - «Операция» — Дата платежа, Дата начисления, Период начисления (с / по), Сумма в валюте счета, Сумма в валюте компании, Статус (план/факт);
    - «Счета» — Со счета, На счет;
    - «Категории» — Категория, Подкатегория;
    - «Контрагенты» — Контрагент, Подконтрагент;
    - «Проекты» — Проект, Подпроект;
    - «Теги и комментарий» — Теги, Комментарий;
  - «Группировка»: Без группировки / По проектам / По категориям / Проект → категория;
  - «Листы»: Один лист / По месяцам;
  - «Операции»: Все / Фактические / Плановые;
  - «Мои шаблоны»: название + «Сохранить как шаблон»;
  - кнопки «Отмена» / «Собрать файл».

## Импорт («Импортировать» с иконками Excel/PDF/CSV, последняя кнопка тулбара)
- Правая панель «Откуда будет импорт?»: поиск, «Открыть все импорты», «AI import», «Сервисы» (Excel, Upwork, PayPal, Binance, …), банки по странам (Казахстан: VTB, Home Credit, Kaspi, Halyk, Alatau City Bank (Jusan), ForteBank, Centercredit, RBK, Freedom), внизу «Хочу импорт из…».
- «Импорт из Excel» (`42-import-excel.png`): зона «Перетяните сюда файл (макс 10 мб)» / «Выберите файл», ссылка «Скачать шаблон», внизу кнопка «Импортировать».
- В «Истории действий» (часы в шапке) есть вкладка «Импорты» с «Отмена» у каждого импорта (`24-history.png`).

## Формат файла (шаблон = выгрузка «Excel»)
Шаблон «Шаблон импорта в Finmap.xlsx»: лист «Шаблон» (данные) и лист «Инструкция» (импортируется только первый лист).

| Кол. | Заголовок | Обяз. | Содержимое |
|---|---|---|---|
| A | Дата платежа* | да | Дата движения денег. В выгрузке — число Excel с временем (доли суток); в шаблоне допускается текст `dd-mm-yyyy` с любым разделителем |
| B | Дата начисления | — | Дата признания дохода/расхода |
| C | Период начисления (дата "с") | — | Для налогов и зарплаты; в выгрузке — текст `01.09.2026 00:00:00`, в шаблоне — число Excel |
| D | Период начисления (дата "по") | — | Конец периода (`30.09.2026 23:59:59`) |
| E | Сумма в валюте счета* | да | Точка или запятая для копеек; больше 2 знаков — округляется. В выгрузке — положительное число |
| F | Сумма в валюте компании | — | Для счетов не в валюте компании; если пусто — курс на дату платежа |
| G | Со счета* | для расхода | Точное название счёта |
| H | На счет* | для дохода | Точное название счёта; обе G и H — перевод |
| I | Категория | — | Стандартные или новые (создаются при импорте) |
| J | Подкатегория | — | Создаётся автоматически |
| K | Контрагент | — | Создаётся; тип зависит от категории («Зарплата» → сотрудник, «Мои категории доходов» → клиент) |
| L | Подконтрагент | — | |
| M | Проект | — | Создаётся автоматически |
| N | Подпроект | — | |
| O | Теги | — | Через запятую |
| P | Комментарий | — | До 1000 символов |

Правила из листа «Инструкция»:
1. Импортируется только первая вкладка.
2. Если хоть одна строка не разбирается — импорт не проходит, Finmap показывает ошибку.
3. Новые категории, контрагенты, проекты, теги создаются автоматически.
4. Счета должны существовать заранее (точное название).
5. «Со счета» — для расхода, «На счет» — для дохода, обе — перевод.
6. Стандартные категории Finmap (8 шт.), среди них «Инвестиции», «Получение кредита», «Возврат займа».

## Особенности настоящей выгрузки
- **Заголовки колонок с латинскими буквами-двойниками** вместо кириллических (`Дата плaтежа`, `Cyммa в вaлюте кoмпaнии`, `Hа счет`, `Kатегoрия`, `Tеги` …). Сопоставлять заголовки нужно после замены латинских двойников (a, c, e, o, p, x, y, A, B, C, E, H, K, M, O, P, T, X) на кириллицу и без учёта регистра.
- Ячейки — `t="str"` с `<v>` (без sharedStrings), даты — числа Excel с дробной частью (время). Пустые ячейки — `t="str"` без `<v>`.
- Объём реальной компании: ~16 тыс. строк, файл ~9,7 МБ (лист ~9,7 МБ XML) — близко к пределу 10 МБ.
- Остатков счетов в выгрузке нет: начальный баланс = текущий остаток в Finmap − сумма операций по счёту.
