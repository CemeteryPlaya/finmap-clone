# «Аналитика клуба», план АК-2 «Загрузка» — итоги

План: [2026-11-06-club-analytics-2.md](../plans/2026-11-06-club-analytics-2.md). Спецификация: [2026-11-03-club-analytics-design.md](../specs/2026-11-03-club-analytics-design.md), решения планирования — §17 (R9–R16).

## Что сделано

- **Расчёт** (`src/shared/club-analytics/load.ts`): слияние наложенных сеансов места, раскладка по часам, загрузка за период, по дням и колонкам шага, карта «день недели × час», часы пик и простоя, итоги зоны. Средние — только по полным дням.
- **Зоны клуба:** таблица `senet_zones` (миграции 0018 / pg 0008), `GET/PUT …/senet/offices/:id/zones`, блок «Зоны» в «Изменить» клуба Senet; удаление подключения чистит зоны.
- **Отчёт «Загрузка»:** `GET …/club-analytics/load`, сеансы ячейки карты `…/load/rows`, Excel `…/load.xlsx`; страница `/analytics/club/load` — карта (по умолчанию), график по шагу «Все зоны / По зонам», таблица зон, «Часы простоя», строка «В расчёте», подсказки о местах.
- **«Обзор»:** плитка «Загрузка ПК», график «Выручка и загрузка по дням», «Часы пик» со ссылкой на «Загрузку»; карточка «Загрузка» на главной «Аналитики».
- **Проверки:** тесты чистых функций и API на обоих диалектах; e2e `club-analytics.spec.ts` (SQLite и PGlite); снимки c80–c82, cm83.

## Решения планирования (§17 спецификации)

- **R9.** Места итога — Σ «Количества ПК» клубов с Senet; если у такого клуба ПК не заданы — места зон и подсказка.
- **R10.** Средние — только по полным дням.
- **R11.** Сеанс без места не сливается.
- **R12.** Сеансы через границу периода обрезаются; берутся начатые не раньше чем за 24 ч до начала.
- **R13.** Вид по умолчанию — первый вид отчёта (у «Загрузки» — карта).
- **R14.** Зоны «Все клубы» с несколькими клубами — «{Клуб} · {зона}».
- **R15.** Ячейка карты — сеансы, пересекающие этот час этого дня недели.
- **R16.** Δ загрузки — в процентных пунктах.

## Чек-лист владельцу

1. Карта «Загрузки» за месяц похожа на то, что вы видите в клубе: пустые утренние часы, вечерний пик, выходные.
2. «Изменить» клуба → «Зоны»: найденные места зон совпадают с числом ПК в зонах; если нет — задайте своё число.
3. «В расчёте: N ПК» совпадает с «Количеством ПК» проекта; подсказки о расхождении нет.
4. «Часы пик» в «Обзоре» и «Часы простоя» на «Загрузке» правдоподобны.
5. Щелчок по часу на карте показывает сеансы этого часа с гостями и местами.
