# Senet: автоматическая разноска — итоги и приёмка

План: `docs/superpowers/plans/2026-11-02-senet-autopost.md`. Спецификация: `docs/superpowers/specs/2026-11-02-senet-autopost-design.md`.

## Чек-лист приёмки с владельцем (С§12.5)

На одном клубе (решение 6), на Vercel.

1. **Подготовка.**
   - В Vercel задан `SECRET_KEY` (README, «Senet — временный источник»), сделан Redeploy.
   - В GitHub заданы секреты `CRON_SECRET` и `APP_URL`, workflow `senet-sync` включён.
   - В Senet заведён отдельный пользователь только для отчётов.
2. **Подключение.** «Интеграции» → «+ Подключить Senet» → «Проверить» показывает клуб и смены за сутки → «Сохранить».
3. **Клуб.** Проект, счета «Касса» и «Kaspi», категория «За смену клуба», постоянная разница кассы +88, клуб выключен.
4. **Правила.** Заполнить алиасы сотрудников, владельцев, мастера, поставщиков бара, ключевые слова (как в `senet_to_finmap.py`). «Проверить на истории» за октябрь — «Распознано N из M», нераспознанные — ожидаемые.
5. **История.** «Загрузить за период» с 01.10.2026 по сегодня. В «Сверке Senet» за октябрь касса после смены сходится (+88) — смены до «Загружать с даты» показаны как «Не проводится».
6. **Автопроводка.**
   - «Предложить» у «Загружать с даты» → начало первой смены после теста через Claude App.
   - Включить клуб.
   - Следующая закрытая смена проводится сама в течение часа после закрытия (пингер GitHub Actions); «Касса после смены» — «Сходится».
7. **Очередь.** Ответ с «Запомнить» → такая же выемка в следующей смене проводится сама.
8. **Удаление.** Удалить проведённую выемку → через час она снова в журнале; удалить с «Не проводить повторно» → не возвращается.
9. **Отказ доступа.** Неверный пароль → баннер «Обновите доступ к Senet — забор остановлен», забор остановлен; новые данные → забор возобновился.
10. **Сверка с эталоном на своей машине:** `npx tsx scripts/senet-parity.ts --since 2026-10-08` → «Расхождений: 0; касса после смены не сходится: 0».

## Открыто

- **Задача 1 (Phase 5, № 37) — пробный забор с владельцем:**
  - колонки `shop_quantity`, `movements_of_goods`, `office_load*`;
  - есть ли список клубов и касс в админ-API;
  - живёт ли старый токен после нового входа.

  После неё — таблицы и разбор `senet_stock`, `senet_goods_moves`, `senet_load` (С§9.3) и точный текст подсказки «как скопировать токен».
- **Продажи бара обрезаются Senet на 2000 строк** (настоящий октябрь кончился 13.10). Забор идёт окнами по суткам и предупреждает при ровно 2000 строк — это объяснение расхождения «669 тыс. против 1,1 млн» из брифа для блока «Аналитика клуба». Проверить на пробном заборе.
- **Сырые xlsx.** Если Senet пишет в xlsx время создания, файлы не совпадают по sha256. Тогда хранится до 3 файлов в час на клуб — около 90 МБ за 90 дней. При нехватке Blob — дедуп по разобранным строкам.
- **Telegram-бот** — отдельная спецификация. API очереди готов: `app.senet.review.answer(…, { via: 'telegram' })`.
