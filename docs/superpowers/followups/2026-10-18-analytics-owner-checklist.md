# «Аналитика»: приёмка владельцем на своих данных

Это чек-лист для владельца, не автотест. Цель: убедиться, что отчёты клона сходятся с вашим журналом и с Finmap на ваших настоящих данных. Расхождения записывайте в таблицу в конце файла **без настоящих сумм**: только «сошлось», «не сошлось, разница порядка X %» и номер шага. Настоящие цифры в репозиторий не вносим.

**Подготовка**
- [ ] Данные компании загружены (импорт из Finmap или ввод) и сверены: `npm run import:check` дал «Итог: Совпадает» (раздел README «Импорт из Finmap»).
- [ ] Для сверки с Finmap открыты те же компания и период в обеих системах. Берите **закрытые месяцы** (не текущий): в текущем ещё идут операции.
- [ ] Курсы валют на даты периода заданы (если есть валютные счета): «Настройки» → «Курсы».
- [ ] Выберите 2–3 эталонных месяца: обычный, с большим расходом и с переводом между валютами (если бывает).
- [ ] Запустите `npm run bench:reports` на этом компьютере (около 10–15 минут): все сценарии с бюджетом должны быть «OK» (не более 300 мс), итог «бюджет соблюдён». Запишите медиану p95 худшего сценария в таблицу.

## 1. «Деньги» (период по дате платежа)
Открыть: «Аналитика» → «Деньги», вид «таблица», шаг «По месяцам», период «Выбрать даты» (эталонный месяц).
- [ ] «Остаток на конец периода» = сумма остатков неархивных счетов в левой панели на конец месяца (для прошлого месяца — по журналу: «остаток после операции» последней операции каждого счёта).
- [ ] «Остаток на начало» следующего месяца = «Остаток на конец» предыдущего.
- [ ] «Поступления» за месяц = сумма доходов журнала за тот же период (журнал: период, тип «Доход»; итог выделения или выгрузка).
- [ ] «Списания» за месяц = сумма расходов журнала за период.
- [ ] «Чистый денежный поток» = «Поступления» − «Списания».
- [ ] Раскройте «Неоперационные изменения остатка»: конец − начало = чистый поток + неоперационные изменения. «Стартовые остатки» не ноль только в месяц открытия счёта; «Переводы» при всех счетах близки к нулю.
- [ ] Валютный счёт (если есть): «Курсовая разница» объяснима — разница курсов между началом и концом месяца.
- [ ] Щёлкните ячейку любой категории: сумма в списке операций под таблицей = число в ячейке.
- [ ] Сверка с Finmap: «Деньги» → таблица, тот же период: «Поступления», «Списания» и остаток на конец совпали (допуск — только округление в копейках).
- [ ] Вид «график»: столбцы и «Сальдо» (поступления − списания) согласованы с таблицей.
- [ ] Ссылка: скопируйте адрес страницы, откройте в новой вкладке — те же период, разрез и шаг.

## 2. «Выписка по счету»
Открыть: «Аналитика» → «Выписка по счету», выбрать один денежный счёт, эталонный месяц.
- [ ] «Остаток на начало» = остаток счёта после последней операции до месяца (журнал, фильтр по счёту).
- [ ] «Остаток на конец» = остаток после последней операции месяца = остаток счёта в левой панели (если месяц последний).
- [ ] Начало + поступления − списания + переводы на счёт − переводы со счёта = конец.
- [ ] Поступления и списания сошлись с итогом выделения журнала по этому счёту и периоду.
- [ ] Перевод между валютами виден в каждой выписке в валюте своего счёта.
- [ ] Сверка с банковской выпиской или Finmap по одному счёту за месяц: остатки на начало и конец совпали.
- [ ] «Excel»: файл открывается, число строк = число операций выписки.

## 3. «Прибыль» (период по дате сделки)
Открыть: «Аналитика» → «Прибыль», вид «таблица», шаг «По месяцам».
- [ ] **Склад выключен («по закупкам»):** «Доходы» и «Расходы» за месяц совпали с Finmap (там склад не учитывается) и с журналом по дате сделки (без переводов и исключённых категорий: инвестиции, дивиденды, займы, кредиты).
- [ ] Исключённые категории в «Расходах» и «Доходах» отсутствуют.
- [ ] **Склад включён («по себестоимости»):**
  - [ ] появились строки «Себестоимость проданных товаров» и «Списания товаров»;
  - [ ] «Расходы» уменьшились на оплаты закупок и выросли на себестоимость: разница со склад-выключен = себестоимость + списания − оплаченные закупки;
  - [ ] нет предупреждения «Нет партии» (или вы знаете, откуда оно: продажа без остатка);
  - [ ] **закупки оплачены через «Оплату закупки»** — откройте «Склад» → «Документы»: у каждого поступления «Оплачено X из Y» без неожиданных «долг» и «0 из Y». Расход на закупку без привязки в «по себестоимости» считается дважды (расход и себестоимость), и прибыль занижена.
- [ ] Щёлкните «Расходы» месяца: список операций сходится с суммой; расход, оплативший закупку, отмечен частью.
- [ ] Для месяца с датой сделки, отличной от даты платежа: операция в нужном месяце (дата сделки), а «Деньги» показывает её в месяце платежа.

## 4. «Проекты»
Открыть: «Аналитика» → «Проекты», статус «Все проекты», режим «Только проекты», тот же период.
- [ ] Сумма строк проектов и «Без проекта» = «Всего».
- [ ] «Всего»: «Доходы», «Расходы» и «Прибыль» = «Прибыль» за тот же период и тот же режим склада.
- [ ] Статус «Активные проекты»: есть строка «Архивные проекты (вместе)» (если у архивных проектов были суммы), «Всего» не изменилось.
- [ ] «Рентабельность, %» = прибыль ÷ доходы, «Доход / Расход, %» = доходы ÷ расходы, там, где расходов нет, — «—».
- [ ] Режим «Проекты с категориями»: сумма категорий проекта = строка проекта.
- [ ] Сверка с Finmap «Проекты» за тот же период (склад выключен): прибыль каждого проекта совпала.
- [ ] Себестоимость продаж записана на проект склада (бар клуба), а не на «Без проекта».

## 5. «Финансовые показатели»
Открыть: «Аналитика» → «Финансовые показатели», период «За текущий год» или эталонный, шаг «По месяцам».
- [ ] Проверьте умолчания (окно «Редактировать показатель» у каждого показателя): состав частей соответствует README («Операционные расходы» без налогов и НДС; у «Компьютерного клуба» «Закуп бара» в себестоимости и переменных).
- [ ] **Валовая прибыль** = выручка − себестоимость (COGS): выручка месяца = «Доходы» из «Прибыли»; себестоимость = склад (FIFO) + выбранные категории.
- [ ] **Маржинальный доход** = выручка − переменные расходы.
- [ ] **EBITDA** = выручка − операционные расходы (без налогов, НДС и инвестиций).
- [ ] **Процент маржи** = «Прибыль» месяца ÷ выручка × 100 (целое); проверьте на калькуляторе по числам из «Прибыли» (склад включён). Месяц без выручки — «—».
- [ ] Сверка с Finmap «Финансовые показатели» (если настроены одинаковые категории): все четыре показателя за эталонный месяц совпали. Различия объясняйте составом категорий и складом, а не округлением.
- [ ] Измените категории одного показателя («Сохранить»): значение изменилось, на вкладке «История» появилась запись «Изменение» с вашим именем и новыми категориями.
- [ ] «Вернуть по умолчанию»: значение вернулось, в «Истории» — «Возврат по умолчанию».
- [ ] Новая категория расхода, созданная после настройки, попала в «Операционные расходы» (потому что выбрано «Все категории»).
- [ ] Щёлкните значение: в списке операций сумма сходится с числом ячейки (кроме строк склада — об этом пометка).
- [ ] «Excel»: в сведениях перечислены категории всех четырёх частей.

## 6. Телефон
- [ ] На телефоне (или в окне 390 px) откройте «Аналитика» → каждый отчёт: страница не уезжает вбок, таблица прокручивается внутри, фильтры — в окне «Фильтры».
- [ ] Кнопки «Excel» и «Обновить» нажимаются пальцем.
