## Заметка для владельца
- **Склад по себестоимости и «Оплата закупки».** Когда включено «Склад: по себестоимости», закупка считается правильно, только если расход, которым она оплачена, привязан через «Оплату закупки». Расход на закупку без привязки считается дважды: как расход и ещё раз как себестоимость при продаже, и прибыль занижается. В README (А-4) описать это правилом; в будущем «Складе» можно проверять расходы «Закуп бара» без привязки при поступлениях в долг.

## Замер скорости
- **Запустить `npm run bench:reports` на машине владельца** до закрытия этапа 2: бюджет 300 мс, замер идёт трижды по 20 вызовов, берётся медиана p95.
- **Решение по замеру:** бюджет 300 мс относится к году в 50 000 строк операций (§3.2). Сценарии «5 лет истории» справочные: это стресс-случай вне бюджета, они не влияют на код выхода.
- **Результат (машина разработки):** пять сценариев бюджета укладываются (медиана p95 от 167 до 267 мс). Сценарии «5 лет истории» не укладываются (справочно): «Деньги» 472 мс, «Прибыль» со складом 319 мс при 205 тысячах операций.
- **Если журнал вырастет:** хранить остаток на начало снимками по месяцам, чтобы не читать все операции до периода; суммы по колонкам при необходимости считать в SQL (проводки периода агрегировать по счёту и колонке через `CASE` по началам колонок вместо одной строки на операцию).

## Отложено (из итогового ревью)
- **Страницы ячейки «Прибыли»:** худший случай цикла добора (O(M²/limit): `livePayments` агрегирует все оплаты); передать `operation_id IN (…)` в `livePayments`, увеличивать порцию после пропусков.
- **`paidByDoc` и «Прибыль»:** различие на черновиках поступлений и плановых оплатах (сейчас черновики не пишутся ни одним путём).
- **R9:** документ `count` в запросе списаний не покрыт тестом; покрыть вместе с инвентаризацией в Склад-2.
- **Стек и столбец:** строка с итогом не больше нуля даёт нулевые значения (API не принимает неположительные строки, склад не уходит ниже нуля) — зафиксировать как инвариант тестом.
- **`compactMoney`:** «1000 тыс» на границе единицы (косметика).
- **Кольцо:** фиксированные 180 px, не тянется (косметика).
- **Цвета графиков:** фраза про различимость при нарушениях цветового зрения в `styles.css` без подтверждения; приложить симуляцию или смягчить комментарий.
- **HelpButton:** якорь подсказки скрыт при пересечении ширины `md` (редко).
- **`useStockWarehouses`** выполняется и на «Деньгах» (один лишний запрос); добавить параметр `enabled`.
- **Панель отчёта:** названия «Проценты: вкл» и «Скрыть проценты»; CSS панели привязан к именам классов (покрыто e2e R10); длинная подпись своего периода на 1440 px — единственный непроверенный риск переноса.
- **Список «Прибыли»:** курсор по дате сделки вместо даты платежа (R5).
