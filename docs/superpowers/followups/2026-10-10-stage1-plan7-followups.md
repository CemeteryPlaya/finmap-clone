# Этап 1, план 7 (мобильная версия и PWA) — итоги и отложенные замечания

**Ветка:** `stage1/plan1-skeleton`, коммиты 73cc19d..01de85f. В этот диапазон входят 7 задач и волна финальных правок 01de85f.

## Проверка
- **План до выполнения.** Harness дважды накладывал план на фактический код.
  - Первая проверка нашла, что форма операции на телефоне вылезает за экран (672 px при ширине 390), а проверка ширины этого не видела.
  - Вторая нашла новый файл, не попавший в коммит, и выход Tab из формы.
  - Всё исправлено: первое — в тексте плана, второе — решениями контролёра при выполнении.
- **Решения контролёра:**
  - каждый новый файл попадает в коммит;
  - Tab не попадает на недоступные элементы, невыбранные переключатели и элементы с `tabindex="-1"`;
  - Tab и Shift+Tab ходят по кругу в форме и в окне архивной компании;
  - в форме архивной компании фокус открытия — на «Закрыть».
- **Ревью задач.** Каждую задачу проверил ревьюер или контролёр.
- **Финальное ревью (opus): «With fixes».**
  - Важное замечание касалось плана 8a: его замена раздела README стёрла бы инструкцию по установке на телефон. Это внесено как обязательное решение при выполнении 8a.
  - Мелочи кода исправлены сразу:
    - заметная рамка фокуса у карточек;
    - 404 для неизвестных путей `/pwa/`;
    - манифест с `crossorigin="use-credentials"` — для туннелей с подтверждением через куку;
    - отрицательная проверка в e2e без фиксированной паузы.
- **Тесты:** vitest 497/497, typecheck чистый, e2e 58/58 в двух прогонах подряд.

## Проверить вручную
- **Установка на настоящем iPhone и Android:** отступы безопасной зоны, иконка, название, запуск с главного экрана. E2E идёт только в Chromium.
- **Установка через бесплатный ngrok:** доходит ли манифест через страницу-предупреждение.

## Отложено (не блокирует)
1. **Предупреждение о недоступных условиях.** Если применить сохранённый фильтр с недоступными условиями из панели фильтров на телефоне, предупреждение показывается под панелью, за затемнением. Лучше закрывать панель при применении.
2. **Фокус после «Сбросить фильтр» в панели.** Фокус пропадает: кнопка исчезает.
3. **Поворот или изменение ширины при открытой панели фильтров.** Теряется ещё не отправленный текст поиска и фокус.
4. **Карточка журнала без подсказки действия.** У кнопки нет подсказки «Открыть операцию», которая есть у строки таблицы.
5. **Медленный e2e бесконечной прокрутки.** Тест создаёт 55 операций по одной; при медленной машине может упереться в таймаут.
6. **Блокировка прокрутки под модальными окнами на iOS.** Страница под ними прокручивается.
7. **Первый запрос иконки 512 px** считается синхронно, около сотни мс один раз, дальше берётся из кэша.
