# «Склад»: приёмка владельцем на своих данных (планы Склад-2 и Склад-3)

Это чек-лист для владельца, не автотест. Цель — проверить перемещение, инвентаризацию, комплекты, импорт и аналитику склада на настоящем баре клуба. Расхождения записывайте в таблицу в конце файла **без настоящих сумм и названий**: только «сошлось», «не сошлось, разница порядка X %» и номер шага. Настоящие цифры в репозиторий не вносим.

**Подготовка**
- [ ] Приложение запущено после обновления: при первом запуске применяются новые миграции (если есть) после резервной копии.
- [ ] У двух клубов есть склады («Настройки» → «Склады»), в каталоге — товары бара с ценами продажи.
- [ ] Начальные остатки внесены поступлением на день начала учёта («Нет партии» иначе не исчезнет — README, раздел «Склад»).

## 1. Импорт каталога и поступлений
- [ ] «Склад» → «Товары» → «Импорт из Excel»: свой файл каталога (столбцы «Название», «Группа», «Единица», «Штрихкод», «Цена продажи»). «Проверить»: «Будет создано» — названия без опечаток, «Уже есть» — товары, которые уже в каталоге. «Загрузить» — товары и группы появились.
- [ ] Файл с ошибкой (например, единица «ящ») — ошибка со строкой и столбцом, «Загрузить» недоступна.
- [ ] «Документы» → «Импорт поступлений» (склад выбран вверху): накладные одного дня и поставщика стали одним поступлением; новые поставщики появились среди контрагентов; повторная загрузка того же файла — «Этот файл уже загружен».

## 2. Перемещение между клубами
- [ ] «+ Перемещение»: «Откуда» — Клуб 1, «Куда» — Клуб 2, несколько товаров. В «Остатках» Клуба 2 они появились с той же себестоимостью, у Клуба 1 — уменьшились.
- [ ] Перемещение больше остатка — «Не хватает …», документ не создаётся.
- [ ] Левая панель: сумма «Склад» по двум клубам не изменилась от перемещения.

## 3. Инвентаризация бара
- [ ] «+ Инвентаризация» на сегодня: в строках — все товары бара с остатком, «Учёт» совпадает с «Остатками».
- [ ] Внесите факт части товаров → «Сохранить черновик» → закройте и откройте снова: факт на месте; остатки пока не изменились.
- [ ] Внесите факт по всем строкам → «Провести»: итог «Недостача на X, излишек на Y»; «Остатки» = факт.
- [ ] «Аналитика» → «Прибыль» (склад «по себестоимости») за этот месяц: недостача видна в «Списании товаров».

## 4. Комплект
- [ ] «Товары» → «+ Товар» → «Комплект»: например, «Чипсы + кола». Продажа комплекта уменьшает остатки обеих составляющих; себестоимость продажи = их сумма.
- [ ] После первой продажи состав комплекта изменить нельзя (подсказка в окне товара).

## 5. Аналитика склада (закрытый месяц)
- [ ] «Склад» → «Аналитика», «Все склады», закрытый месяц: «Выручка» = сумма продаж месяца в «Документах»; «Себестоимость» = сумма себестоимости продаж.
- [ ] Строка итогов: «Закуплено за период» = сумма поступлений месяца; изменение стоимости склада = стоимость на конец − на начало (левая панель, «Остатки» на даты).
- [ ] Равенство «на начало + закуплено + излишки − себестоимость − потери = на конец» выполняется.
- [ ] Сверка с журналом: прибыль склада и «Прибыль» журнала за месяц различаются на изменение стоимости склада (§6.2) — при условии, что оплаты закупок привязаны «Оплатой закупки».
- [ ] Товар, закупка которого подорожала, а цена продажи прежняя: в «Динамике цен» подсказка «Закупка выросла на N% …».
- [ ] Списки «Мало», «Без движения 30 дней», «Нет партии» соответствуют вашему бару.
- [ ] «Excel»: листы «Товары» и «Итоги», цифры как на экране.
