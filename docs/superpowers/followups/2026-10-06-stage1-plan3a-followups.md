## Решения, принятые по ходу выполнения

1. **Волна итоговых правок.** Исправлено:
   - порядок дочерних статей в архивной группе;
   - черновик контрагента сохраняется при смене вкладки;
   - видимая ошибка для неверной доли в шаблоне разделения;
   - правильный вид статей при удалённой первой статье шаблона;
   - вывод вложенных ошибок сервера.

   Ревьюер советовал закрыть их в первую очередь. Если решение неверно, откатывается один небольшой коммит `5164793`.
2. **Escape-последовательности.** Инструмент записи файлов превращал `\uXXXX` в буквальные невидимые символы. После каждой записи исполнители прогоняли скрипт, который возвращает `\uXXXX` (задача 1 исправлена отдельным коммитом `7cc008e`).
3. **Висящие ссылки на проект.** После удаления проекта на него могут ссылаться строки шаблонов разделения. По инварианту 10 это допустимо: ссылки в JSON не защищены, при применении шаблона недоступные строки отбрасываются.

## Отложенные мелкие замечания (бэклог)

**Сервер:**
- `changedFields` сравнивает через `JSON.stringify`, то есть зависит от порядка ключей. Сейчас безопасно: обе стороны приходят из zod в одном порядке.
- `validate()` счетов дублирует правила zod, у `startingBalance` сообщения различаются.
- `setArchived` и `reorder` почти одинаковы во всех сервисах справочников — кандидат на общий помощник.
- `CounterpartyType` импортируется из `system-categories`, а схема берёт `COUNTERPARTY_TYPES` из `counterparties`: два источника.
- Блок `migrateWithBackup` повторяется в `setup.ts` и `user-add.ts`.
- В `move()` проверка архива стоит после проверок вложенности, поэтому сообщения идут не в лучшем порядке.

**Тесты:**
- Не хватает случаев:
  - запись в архивную компанию для статей, тегов и шаблонов разделения;
  - устаревший `reorder` для тегов и шаблонов;
  - переименование архивного тега;
  - `unarchive` шаблона разделения.
- Нет компонентных тестов `Pending`, `StaleNotice`, `ConfirmDelete`.
- `category-moves`: нет случаев «`beforeId` не из группы» и сдвига нижнего дочернего элемента.
- Тест отката проверяет не все вызовы `mutate`.

**Интерфейс:**
- Кнопки архива и удаления не блокируются, пока выполняется действие: двойной клик даёт повторный запрос. Затронуты «Счета» и «Проекты».
- Неверное перетаскивание статьи ничего не сообщает. Перетаскиванием нельзя вложить статью в пустую группу; это делается через «Перенести в…».
- Перетаскивание и список «Перенести в…» не блокируются во время запроса (при конфликте сервер отвечает 409, данные обновляются).
- Новый контрагент, который не подходит под фильтр, пропадает без сообщения. Теги не сортируются «архивные в конце». Во вкладках контрагентов нет навигации стрелками.
- Ключ строки компании включает название и валюту, поэтому после обновления данных несохранённая правка теряется (было и раньше).
- `installZodRu` нельзя сбросить в тестах. Импорт `zod-ru` стоит не по порядку.
